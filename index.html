Como funciona de verdade

  1. O cliente manda mensagem para o número do negócio, pela API oficial do WhatsApp (Meta).
  2. Um fluxo no n8n recebe a mensagem e passa para uma IA com as informações do negócio: preços, horários, endereço e regras.
  3. A IA responde em segundos, anota pedidos e chama uma pessoa quando precisa.
  4. Nada é confirmado sozinho: a equipe confirma os horários.

Nesta demonstração as respostas seguem regras simples, para funcionar sem internet e sem custo. O fluxo do n8n está no repositório.
